# Plan: Caddy Poker 2026 — Custom WordPress Marketing Theme

## Context

We need a marketing website for the **Caddy Poker mobile app** (an Expo/React Native golf-poker
game, sister repo at `/Users/amontalbano/git/caddy-poker-app`). The site will run on WordPress
hosted at Bluehost. It needs a **custom theme called "Caddy Poker 2026"** with two pages:

1. **Main landing page** for the app, with "iOS — Coming Soon" and "Android — Coming Soon"
   placeholder areas that will later become real App Store / Play Store buttons.
2. **How to Play** page that embeds the app's existing tutorial video.

The physical card game already sells at https://caddypoker.com. This site is app-focused; it will
carry only a subtle footer link to the physical game store.

The `caddy-poker-website` repo is currently empty (just a README + git). This plan scaffolds the
theme, a local WordPress dev environment for previewing/iterating before deploying to Bluehost, and
copies the needed brand assets from the app repo.

### Decisions locked in (from user)
- **Theme type:** Classic PHP theme (`style.css` + PHP templates). Full design control, simplest on Bluehost.
- **Physical game:** Subtle footer link to caddypoker.com only — no prominent Buy CTA.
- **How to Play:** Embed the app's `caddypoker-how-to-play.mp4` tutorial video.
- **Local dev:** Scripted local WordPress in this repo via `@wordpress/env` (Docker), theme mounted live.

## Page designs

### front-page.php (main app landing)
- **Header:** logo + minimal nav (Home, How to Play). Transparent over hero.
- **Hero:** `cp-landscaping` backdrop with drifting clouds, centered `cp-logo`, tagline
  "Play Golf. Play Poker. Play Both.", short subhead describing the app.
- **Coming-soon buttons block:** two placeholder buttons — **"iOS — Coming Soon"** and
  **"Android — Coming Soon"**, styled as disabled store badges. Build each as an `<a>` with a
  `data-store` attribute and a clearly-marked `TODO: replace href` so swapping to live App
  Store / Play Store links later is a one-line edit. Mirror the app's gold-on-green CTA styling.
- **Features section:** 3–4 cards using golfer mascots explaining the game
  (draw challenge cards → complete on the course → build a poker hand). Voice from app README.
- **Deck showcase:** a small gallery/fan of card fronts to show the physical-meets-app product.
- **Footer:** credit "a montalbano amusement" + subtle "Get the physical game →" link to
  https://caddypoker.com.

### page-how-to-play.php
- Header + hero strip with title "How to Play".
- **Embedded tutorial video** (`<video>` with poster, `controls`, `preload="metadata"`, the
  compressed mp4). Responsive 16:9 wrapper.
- Below the video, a concise written summary of the flow (Before the round → During → After →
  best 5-card hand wins), so the page has SEO text and works if the video is slow. Content drawn
  from caddypoker.com/pages/how-to-play (Hazard/Hole/Caddy cards, one-putts, variants).
- Footer (shared).

## Implementation steps

1. **Scaffold repo:** create `docs/plans/` and commit this plan as
   `docs/plans/20260705_2326_caddy-poker-2026-theme.md`; add `.gitignore`, `package.json`
   (with `@wordpress/env` devDependency + `start`/`stop`/`clean` scripts), and `.wp-env.json`
   pointing `themes` at `./wp-content/themes/caddy-poker-2026` and setting it active.
2. **Theme skeleton:** `style.css` (theme header: name "Caddy Poker 2026"), `functions.php`
   (theme setup, register nav menu, enqueue `assets/css/main.css` + `assets/js/main.js` with
   versioning via `filemtime`), `header.php`, `footer.php`, `index.php`.
3. **Brand CSS:** in `assets/css/main.css`, declare the palette above as `:root` CSS custom
   properties; base typography (heavy weights), layout utilities, responsive breakpoints.
4. **Copy + optimize assets** from the app repo into `assets/img/` and `assets/video/` (downscale
   large PNGs, compress video, generate favicon + poster).
5. **Build `front-page.php`** (hero, coming-soon placeholders, features, deck showcase, footer link).
6. **Build `page-how-to-play.php`** (video embed + written rules).
7. **WordPress wiring:** document that after `wp-env start`, create two Pages in WP admin — Home
   (set as static front page under Settings → Reading) and "How to Play" (slug `how-to-play`, uses
   the page template) — and build the nav menu. Alternatively add a small `functions.php` routine or
   WP-CLI snippet in the README to auto-create these pages/menu on setup.
8. **README:** local dev instructions (`npm install`, `npm start` → http://localhost:8888,
   admin at `/wp-admin`), and Bluehost deploy instructions (zip the
   `caddy-poker-2026` folder → Appearance → Themes → Add New → Upload → Activate; create the two
   pages + menu the same way).

## Verification

- **Local render:** `npm install` then `npm start` (wp-env). Confirm WordPress boots at
  http://localhost:8888; activate the Caddy Poker 2026 theme; create Home + How to Play pages.
- Confirm the **front page** shows the hero, tagline, and both "Coming Soon" placeholder buttons,
  and that the footer physical-game link points to caddypoker.com.
- Confirm the **How to Play** page plays the embedded video and shows the written rules.
- **Responsive check:** verify hero, buttons, features, and video wrapper look correct at mobile
  (~375px) and desktop widths; no horizontal scroll.
- **Deploy dry-run:** zip the theme folder and confirm it installs cleanly via Appearance → Themes →
  Upload on a WordPress instance (validates it's a self-contained, Bluehost-uploadable theme).
